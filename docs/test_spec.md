本系统的核心是严谨的物理与数学解算，**“没有数学证明与对比校验的代码，默认就是 Bug”**。
所有后端模块必须使用 `pytest` 框架进行高度覆盖。测试用例必须包含以下四个维度的绝对防御：

## 1. 物理解析解对比测试 (Analytical Validation)
这是测试引擎准确性的最高标准。对于有明确数学解析解的简单物理系统，数值求解的结果必须在给定容差范围内与理论公式完美吻合。

* **单摆周期测试 (Single Pendulum)**：
  * **输入**：摆长 $L=1.0$，重力 $g=9.8$，极小初始摆角 $\theta_0 = 0.05$ rad（满足小角近似）。
  * **断言 (Assert)**：积分 10 秒后，通过速度过零点计算出的平均运动周期 $T_{num}$，必须与理论周期 $T = 2\pi\sqrt{L/g}$ 的误差小于 $10^{-4}$。
* **弹簧振子频率测试 (Spring Oscillator)**：
  * **输入**：质量 $m=1.0$，劲度系数 $k=100.0$，无重力。
  * **断言**：位移序列应完美拟合 $x(t) = A \cos(\omega t + \phi)$，其中理论角频率 $\omega = \sqrt{k/m} = 10.0$。

## 2. 核心守恒律校验 (Conservation Laws Assertion)
对于不含显含时约束（非定常约束）且无耗散（无摩擦）的保守系统，时间如何流逝，引擎的能量池必须如死水一般平静！
**全局规则**：从 Phase 1 起，所有包含 MassPoint 的测试用例**必须验证能量守恒**。动量守恒仅适用于无外部定常约束的孤立系统（即没有任何 Fixed Anchor 的系统）。

* **机械能守恒测试 (Energy Conservation)**：
  * **系统**：混沌双摆 (Double Pendulum) 等复杂非线性系统，受限或无外部约束。
  * **断言**：在长达 $t=50$ 秒的积分区间内，提取任意时刻 $t_i$ 的系统状态，重新计算 $E(t_i) = T(t_i) + V(t_i)$。
  * **条件**：所有时间步的总能量漂移比例 $\frac{\max(E) - \min(E)}{E_0}$ 必须小于 `5%`。Baumgarte 稳定化会引入少量人工耗散，纯能量守恒需改用辛积分器。
* **动量守恒测试 (Momentum Conservation)**：
  * **适用范围**：仅对无固定锚点（Anchor）的孤立系统进行校验（如自由漂浮的多体系统）。
  * **断言**：提取任意时刻 $t_i$ 的系统总动量 $\vec{P}(t_i) = \sum m_i \vec{v}_i(t_i)$。
  * **条件**：动量漂移绝对值 $\max(|\vec{P}(t_i) - \vec{P}(0)|)$ 须小于 `0.5`。

## 3. 约束漂移与稳定化防御 (Constraint Drift Tolerance)
既然我们引入了 Baumgarte 稳定法，就必须证明它在起作用。

* **杆长刚性测试 (Rigid Rod Tolerance)**：
  * **场景**：三连杆机构快速旋转。
  * **断言**：提取每一帧中通过杆件相连的两个质点坐标 $(x_1, y_1)$ 和 $(x_2, y_2)$。
  * **条件**：在所有时间步中，实时距离 $d_{num}$ 与定义杆长 $L$ 的绝对误差 $|d_{num} - L|$ 永远不得超过 `1e-5`。

## 4. 极端边界与容错测试 (Edge Cases & Fault Injection)
必须对引擎的鲁棒性进行暴力破坏测试，确保系统是优雅地报错，而不是默默算出 `NaN`。

* **初值流形投影测试 (Initial Projection Test)**：
  * 故意向前端 JSON 写入非法的初始状态（如两点间距 $d=5$，但由 $L=3$ 的轻杆连接）。
  * **断言**：后端必须能通过 Newton-Raphson 迭代自动将其投影修正到合法坐标，或者在迭代超限时抛出明确的 `TopologyError` 自定义异常。
* **奇点免疫测试 (Singular Configurations)**：
  * 构建过约束系统（Over-constrained，如三根固定杆将一个质点焊死）。
  * **断言**：系统必须能利用 SVD 伪逆矩阵安全度过求导阶段，并输出静态（加速度为 0）的结果，绝不允许抛出 `SingularMatrixError`。
