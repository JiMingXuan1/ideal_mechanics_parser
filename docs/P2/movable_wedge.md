# 可动斜面 (Movable Wedge)

## 问题

物理竞赛中经典问题：一个有质量、有几何尺寸的斜面（楔形块）放置在光滑平面上，滑块从斜面顶端释放，沿斜面滑下。斜面本身因水平方向动量守恒而水平移动。

Phase 1 的约束均为固定参照系中的绝对约束。可动斜面需要**局部坐标系** + **边界检测** + **状态突变**。

## 模型

### 斜面实体

可动斜面是一个**刚性体**，具有：

| 属性 | 符号 | 说明 |
|------|------|------|
| 质量 | $M$ | 斜面总质量 |
| 宽度 | $W$ | 水平方向长度 |
| 高度 | $H$ | 竖直方向高度 |
| 倾角 | $\alpha$ | $\tan\alpha = H/W$ |
| 位置 | $(x_W, y_W)$ | 斜面左下角的世界坐标 |
| 速度 | $(vx_W, vy_W)$ | 平动速度 |
| 转动惯量 | $I_W$ | 绕质心的惯量（如适用） |

### 局部坐标系

斜面定义局部坐标系 $(u, v)$：

- $u$：沿斜面方向（向上为正）
- $v$：垂直斜面方向（指向斜面外为正）

变换到世界坐标：

```
P_world = (x_W + u·cosα,  y_W + u·sinα)   （沿斜面表面）
```

### 滑块约束

滑块（质点 $m$）被约束在斜面表面滑动：

```
约束方程:  f = (P_m - P_W) · n  = 0
```

其中 $n = (-\sin\alpha, \cos\alpha)$ 为斜面法向量（垂直斜面）。

展开后：

```
f = (x_m - x_W)·(-sinα) + (y_m - y_W)·cosα = 0
```

即滑块到斜面表面的**垂直距离恒为零**。

## 运动方程

系统有 4 个自由度：
- 斜面：$x_W$（水平方向，$y_W$ 固定为 0 或由地面支持力确定）
- 滑块：$x_m, y_m$（受 1 个斜面约束 = 1 个有效自由度）

### 约束

滑块约束（如上） + 斜面水平约束（$y_W = 0$，固定在地面）。

### 动能

```
T = ½ M·vx_W² + ½ m·(vx_m² + vy_m²)
```

### 势能

```
V = m·g·y_m + M·g·y_W
```

## 边界检测 — 离开斜面

滑块沿斜面移动到 $u < 0$ 或 $u > L$（$L = \sqrt{W^2 + H^2}$ 为斜面长度）时，离开斜面。

### 事件定义

```python
def slide_off_event(t, state):
    """滑块距离斜面底端 (u=0) 或顶端 (u=L) 的偏移量"""
    u = get_u(state)  # 滑块在斜面局部坐标中的 u 值
    return max(0 - u, u - L)  # 正 = 在边界内，负 = 已越界
```

### 触发后动作

1. 终止当前积分
2. 移除滑块约束方程
3. 滑块转换为自由质点（仅受重力）
4. 以当前 $q, qd$ 重启积分

## 碰撞检测（滑块落回斜面）

滑块离开斜面后做抛物线运动，可能重新落回斜面表面。此时需要检测碰撞：

```python
def land_on_wedge_event(t, state):
    """滑块是否回到斜面表面范围"""
    if 不在斜面水平范围内: return 1 (无事件)
    计算滑块到斜面表面的垂直距离
    return 距离 (正 = 在表面上方, 负 = 穿透)
```

触发后应用完全非弹性碰撞（滑块停在斜面表面）或恢复系数 $e$ 的弹性碰撞。

```json
      "type": "MassPoint",
      "params": {

        "on_wedge": "wedge1",
        "initial_u": 3.5
      },
      "init_state": {
        "x": 1.6, "y": 2.4,

      }
    }

```

滑块通过 `params.on_wedge` 声明它附着在哪个斜面上。`initial_u` 为滑块在斜面上的初始沿面位置（自动换算为世界坐标 x, y）。

## 渲染

前端渲染 MovableWedge 为一个**直角三角形**，斜边为滑块轨道。

```
       /|
      / |
     /  |  H
    /   |
   /α___|
      W
```

带角度标注 $\alpha$ 和表面方向指示箭头。

## 限制

- 斜面为刚性，不变形
- 地面为光滑刚性平面（无摩擦）
- 仅支持一个滑块附着在一个斜面上（不支持多滑块同斜面）
- 滑块离开斜面后不回头检测重新附着（较复杂，留待优化）
- 斜面仅做平动，不对自身做旋转（防止复杂耦合）
