# 两两碰撞检测

## 问题

刚体/质点在运动中与其他质点或边界发生接触时，需要在碰撞瞬间改变速度方向（恢复系数 $e$）。

## 架构

### 事件定义

使用 SciPy `solve_ivp` 的 `events` 参数。每个可能的碰撞对注册一个事件函数：

```
事件: 距离 - (半径和) = 0
    event(t, state) = ||p_i - p_j|| - (r_i + r_j)
    terminal = True    # 触发后终止积分
    direction = -1     # 仅监控距离由正变负（接近）
```

### 碰撞响应

事件触发后的处理流程：

```
1. 终止当前 solve_ivp 进程
2. 提取碰撞时刻的状态 q, qd
3. 计算碰撞法线方向: n = (p_i - p_j) / ||p_i - p_j||
4. 恢复系数 e 沿法线方向应用冲量跳变:
   v_rel = n · (v_i - v_j)
   若 v_rel < 0（正在靠近）:
     J = -(1 + e) * v_rel / (1/m_i + 1/m_j)
     v_i ← v_i + J/m_i * n
     v_j ← v_j - J/m_j * n
5. 以新速度重新启动 solve_ivp（拓扑不变）
```

### 多体碰撞近似

**P2 不实现真正的多体同时碰撞求解器**。当三个以上物体同时接触时：

1. 将碰撞事件按极短时间窗口内的多次独立双体碰撞处理
2. 每次只处理一对，处理完后检查是否触发新的碰撞
3. 限制窗口内迭代次数（如最多 5 次），防止无限循环

### 限制

- 仅支持 pairwise 碰撞
- 不支持连续接触（堆叠、静摩擦，留给 P3 LCP 引擎）
