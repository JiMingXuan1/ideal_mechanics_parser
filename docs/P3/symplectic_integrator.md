# 辛积分器研究笔记

## 动机

Radau 是隐式 Runge-Kutta 方法，具备 A 稳定性和 L 稳定性，适合刚性方程。但它不是辛的 (symplectic)，因此不保能量。

对于**无约束系统**（如弹簧振子、纯弹簧耦合系统），辛积分器可以实现机器精度的能量守恒（$10^{-12}$ 级别）。

## 候选方法

### Verlet 积分 (Störmer-Verlet)

最简单的一阶辛积分器：

```
q_{n+1/2} = q_n + (h/2) * v_n
v_{n+1}   = v_n + h * a(q_{n+1/2})
q_{n+1}   = q_{n+1/2} + (h/2) * v_{n+1}
```

- 显式，二阶精度
- 对弹簧振子系统能量守恒达到机器精度
- 不适用于刚性约束（需要隐式版本）

### 隐式中点法

$$
\frac{q_{n+1} - q_n}{h} = \frac{v_{n+1} + v_n}{2}, \quad
\frac{v_{n+1} - v_n}{h} = a\Big(\frac{q_{n+1} + q_n}{2}\Big)
$$

- 隐式，二阶精度
- 辛，能量守恒
- 每一步需要非线性求解
- 可与约束投影结合

## 适用性

| 系统类型 | Radau | Verlet | 隐式中点 |
|---------|-------|--------|---------|
| 无约束多体 | 可以 | **推荐** | 可以 |
| 刚性约束 | **推荐** | 不稳定 | 需要投影 |
| 混合弹簧+杆 | **推荐** | 不稳定 | 需要投影 |

## 结论

P3 的辛积分器只适合作为**无约束系统的独立求解路径**。对于约束系统，仍需 Radau + 后稳定投影的组合。
